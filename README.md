## Production Workflow Quick Reference

Every shot follows the **Golden Rule** to eliminate visual drift:
1. **Frame Image (Nano Banana):** Generate a 9:16 still image with Character + Location Plate attached to lock composition.
2. **Video Animation (Veo):** Switch model to Veo, attach the still image as the first frame, and generate the 10-second clip with narration.
3. **Edit & Trim:** Trim each 10s raw clip to its spoken line (~6–8s), stack sequentially, and loop Shot 08 back into Shot 01.
